PRAS · Seguridad

Backup y restore

Realiza copias de seguridad de las bases PRAS y PRAS_Seguridad y las restaura.

Cómo se usa

  1. Backup: elija el archivo de destino y toque Realizar backup.
  2. Restore: elija el archivo .bak y toque Restaurar.

Importante: Al restaurar se reemplazan TODOS los datos actuales y se cierra la sesión.

Ayuda: tecla F1 en cualquier pantalla · Sistema > Ayuda · Sistema > Pedir ayuda
