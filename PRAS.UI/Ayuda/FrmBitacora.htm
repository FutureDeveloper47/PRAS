Bitácora

Muestra todo lo que registró el sistema: inicios de sesión, altas, modificaciones, errores y pedidos de ayuda.

Cómo se usa

  1. Filtre por fechas, nivel, usuario o texto y toque Buscar.
  2. Doble clic en una fila para ver el registro completo.

Importante: Amarillo = advertencia. Rojo = error. Los mensajes se guardan en español y se muestran en el idioma elegido.

Ayuda: tecla F1 en cualquier pantalla · Sistema > Ayuda · Sistema > Pedir ayuda
