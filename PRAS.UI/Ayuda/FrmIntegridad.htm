Integridad de datos

Verifica con dígitos verificadores (DVH por registro y DVV por tabla) que nadie haya modificado la base por fuera del sistema.

Cómo se usa

  1. Toque "Verificar nuevamente" para revisar las tablas protegidas.
  2. Si los cambios son correctos, toque "Recalcular dígitos".
  3. Si no, toque "Restaurar backup..." y elija un backup anterior al problema.

Importante: Para probarlo: cambie un dato de Cliente o Usuario con SQL Server Management Studio y vuelva a verificar.
