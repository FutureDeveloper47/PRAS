Permisos (familias y patentes)

Administra los permisos con el patrón Composite: una patente es un permiso concreto y una familia agrupa patentes y otras familias.

Cómo se usa

  1. Cree familias y agrégueles patentes o familias.
  2. Asigne familias o patentes a cada usuario.

Importante: No se puede asignar un permiso que el usuario ya tiene (directo o dentro de una familia) ni armar familias cíclicas.

Ayuda: tecla F1 en cualquier pantalla · Sistema > Ayuda · Sistema > Pedir ayuda
