Restablecer contraseña

El administrador le pone una contraseña temporal a otro usuario (por ejemplo, si se la olvidó y no tiene pregunta de seguridad).

Cómo se usa

  1. Abra Sistema > Mi perfil > Administrar usuarios.
  2. Seleccione el usuario y toque "Restablecer contraseña".
  3. Escriba la contraseña temporal dos veces (6 caracteres o más) y toque Guardar.
  4. Comuníquele la contraseña al usuario: después la puede cambiar en Mi perfil.

Importante: Las contraseñas no se pueden ver: se guardan con hash SHA-256. Su propia contraseña no se restablece desde acá: se cambia en Mi perfil escribiendo la actual.

Ayuda: tecla F1 en cualquier pantalla · Sistema > Ayuda · Sistema > Pedir ayuda
