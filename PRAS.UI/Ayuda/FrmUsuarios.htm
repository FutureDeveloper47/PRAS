Usuarios

Lista de todos los usuarios (usuario, nombre, rol, estado y último ingreso) con su alta, modificación, habilitación, deshabilitación y restablecimiento de contraseña. Se abre desde Seguridad > Usuarios o desde Mi perfil > Administrar usuarios.

Cómo se usa

  1. Toque Nuevo para crear un usuario y elija su rol (Dueño, Administrador o Mecánico).
  2. Seleccione un usuario y toque Modificar para cambiar sus datos.
  3. Deshabilitar: el usuario ya no puede ingresar (no se borra). Habilitar: vuelve a poder ingresar (así se aprueban las cuentas pedidas desde "Solicitar acceso").
  4. Restablecer contraseña: le pone una contraseña temporal a otro usuario.

Importante: Las contraseñas no se muestran nunca (se guardan con hash SHA-256). Siempre debe quedar al menos un Administrador activo. Nadie puede deshabilitarse a sí mismo.
