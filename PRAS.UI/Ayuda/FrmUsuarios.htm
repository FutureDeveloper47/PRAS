Usuarios

Alta, modificación, deshabilitación y habilitación de usuarios del sistema.

Cómo se usa

  1. Toque Nuevo para crear un usuario y elija su rol (Dueño, Administrador o Mecánico).
  2. Seleccione un usuario y toque Modificar para cambiar sus datos.
  3. Deshabilitar: el usuario ya no puede ingresar (no se borra).

Importante: Siempre debe quedar al menos un Administrador activo. Nadie puede deshabilitarse a sí mismo.

Ayuda: tecla F1 en cualquier pantalla · Sistema > Ayuda · Sistema > Pedir ayuda
