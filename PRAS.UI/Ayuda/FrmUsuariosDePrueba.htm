Usuarios de prueba

Tabla con los usuarios para mostrar el sistema: usuario, contraseña de prueba, rol y nombre. Se abre desde el link "Usuarios de prueba" de la pantalla de ingreso.

Cómo se usa

  1. Haga doble clic en un usuario para copiarlo en la casilla "Usuario" del ingreso.
  2. Escriba la contraseña que muestra la tabla y toque Ingresar.
  3. La respuesta de la pregunta de seguridad de todos los usuarios de prueba es "pras".

Importante: Las contraseñas que se ven son las de PRUEBA, fijas y conocidas: no se leen de la base (ahí solo está el hash SHA-256). Si alguien cambió la suya, aparece "(cambiada)". El link solo aparece si el archivo de configuración tiene MostrarUsuariosDePrueba = true; en una instalación real se pone en false.
